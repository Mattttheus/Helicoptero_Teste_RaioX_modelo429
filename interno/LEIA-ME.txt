MANUTENÇÃO INTERATIVA – pasta interna (NÃO vai para o git nem para o GitHub Pages)

Dados extraídos dos manuais da Bell (material proprietário – uso interno de manutenção da Helipark).

  indice_manuais_bell.json   Índice de todos os procedimentos (título, tipo, DMC/capítulo, link para o portal), texto das
                             descrições de sistemas, peças do IPC (item, PN, nomenclatura, efetividade, UPA), lista de
                             figuras e páginas de figura dos manuais por capítulo.
  textos_<modelo>.json       Texto completo de todos os procedimentos (IETM: 505, 407, 407GXi, 429) ou de todas as
                             páginas dos manuais por capítulo (206B, 206L4, 230, 430 – MM e IPB).
  figuras/                   Figuras detalhadas: ICN-....svg (IETM) e <capítulo>_p<n>.png (páginas de figura).
                             Vêm dentro dos figuras_<modelo>.zip: extraia os .zip AQUI (cria a pasta figuras/).

Como gerar/atualizar:
  1. No Chrome, entre em https://www.bellhelicopter.net/tp/ com a conta Bell da Helipark.
  2. F12 → aba Console → cole o conteúdo de ferramentas/indice_bell_console.js → Enter.
     Aceite "permitir vários downloads". Deixe a aba aberta: a frota toda leva dezenas de minutos e alguns GB
     de figuras (o progresso aparece no Console). Para baixar só alguns modelos, rode antes no Console:
       window.__MI_MODELOS = ['505'];      (ou outros)
     e para limitar as figuras a alguns capítulos:
       window.__MI_FIGURAS = ['67','76'];
  3. Mova para esta pasta: indice_manuais_bell.json, textos_*.json e extraia aqui os figuras_*.zip.

Os links abrem o procedimento no portal Bell (exige login).
